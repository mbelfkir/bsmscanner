# SMEFT Wilson-coefficient benchmark

Reference:

```text
B. Grzadkowski, M. Iskrzynski, M. Misiak, J. Rosiek,
Dimension-Six Terms in the Standard Model Lagrangian,
JHEP 10, 085 (2010), arXiv:1008.4884.
```

This benchmark implements a compact Warsaw-basis dimension-six scan with
electroweak and Higgs-rate proxy observables at fixed EFT scale.
