# Two-Higgs-doublet benchmark

Reference:

```text
G. C. Branco et al.,
Theory and phenomenology of two-Higgs-doublet models,
Phys. Rept. 516, 1-102 (2012), arXiv:1106.0034.
```

This benchmark uses CP-conserving physical masses, tan beta, alignment, and a
soft-breaking parameter to produce Higgs-signal, oblique-T, perturbativity, and
stability proxy observables.
