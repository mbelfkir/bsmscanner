# BSMScanner Static Documentation Site

Open `index.html` directly in a browser, or serve this directory locally:

```bash
.venv/bin/python -m http.server 8000 -d docs/site
```

Then visit:

```text
http://localhost:8000
```

The site is intentionally static and dependency-free, so it can later be
published with GitHub Pages or any standard static hosting service.
